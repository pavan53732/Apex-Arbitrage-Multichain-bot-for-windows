- **Run Data Preprocessing:** Execute the Python preprocessing script to prepare the datasets for training: `python train\preprocess.py`.
- **Run Feature Extraction:** Execute the Node.js feature extractor to generate `features.csv` from the raw trade history.
- **Execute Model Training (Optional):** To retrain the models, run the main training script using `python train\train.py --config train\config.yaml`.
- **Start the AI Engine:** Launch the main AI engine process from the `ai-modules` root directory by running `node ai-engine.js`.
- **Run Integration Tests:** Execute the test suite to ensure all modules are functioning correctly on the Windows environment: `npm test`.
