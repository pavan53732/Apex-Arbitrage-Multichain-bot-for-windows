# Performance Targets

## Purpose
Defines measurable response-time, throughput, latency, recovery, and freshness targets.

## Target categories
- UI response latency.
- IPC round-trip latency.
- Market data freshness.
- Opportunity ranking latency.
- Execution planning latency.
- Reconciliation latency.
- Restart and recovery time.
- Queue backlog bounds.
