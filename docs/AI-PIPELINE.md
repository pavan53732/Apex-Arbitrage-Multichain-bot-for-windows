# AI Pipeline

## Purpose
Defines AI decision lifecycle, prompt lifecycle, routing, scoring, explainability, and safety gating.

## Lifecycle
Context assemble -> Prompt build -> Provider select -> Model invoke -> Score -> Validate -> Approve/Reject -> Execute or Hold -> Persist feedback.
