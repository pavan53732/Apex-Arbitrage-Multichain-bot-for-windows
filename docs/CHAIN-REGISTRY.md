# Chain Registry

## Purpose
Defines the authoritative registry of supported chains and chain-level capabilities.

## Scope
This registry is descriptive and feeds chain integration, routing, wallet, gas, and deployment decisions.

## Fields
- Chain name.
- Chain id.
- RPC endpoints.
- Explorer URL.
- Native token.
- Gas model.
- Supported DEXs.
- Flash loan support.
- Finality profile.
- Feature flags.
