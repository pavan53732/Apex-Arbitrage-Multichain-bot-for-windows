# Recovery and Failover

## Purpose
Owns recovery workflows, failover policy, restoration order, and fail-closed behavior.

## Responsibilities
- Define recovery triggers.
- Define failover order across workers, services, and data sources.
- Define restore and rollback steps.
- Ensure critical subsystems fail closed.
