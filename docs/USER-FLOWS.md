# User Flows

## Purpose
Defines end-to-end user journeys from first launch through live operations and recovery.

## Covered flows
- First launch.
- Initial setup.
- AI provider onboarding.
- Wallet onboarding.
- Chain onboarding.
- Strategy creation and configuration.
- Backtesting and paper trading.
- Live trading and monitoring.
- Emergency stop and crash recovery.
- Backup, restore, import, export, updates, and settings management.

## Flow structure
Each flow defines preconditions, user actions, system actions, validations, failure paths, recovery paths, and completion criteria.
