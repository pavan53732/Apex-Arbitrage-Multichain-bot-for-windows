# Exports & Backups

Full system exports, backups, and data bundles.

## Export Types
- **Full Backup**: Complete dashboard state, settings, data
- **CSV Export**: All CSV data bundled
- **Preset Export**: Dashboard configurations only
- **User Data**: Per-user data export

## Format
- ZIP archives for multi-file exports
- JSON for single-file exports
- Encrypted for sensitive data

## Scheduling
- Daily auto-backups
- Weekly full backups
- On-demand manual exports

## Restore
- Select backup file
- Verify integrity
- Apply restore (with rollback option)

## Storage
- Local: Stored in exports/ folder
- S3: Optional cloud backup
- Retention: 30 days default
