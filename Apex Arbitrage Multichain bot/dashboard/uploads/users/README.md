# User Uploads

Per-user file storage for avatars, custom data, and personal uploads.

## Structure

- Each user has a dedicated subfolder
- Folder name: username or user_id
- Privacy: User files are isolated and protected

## Supported Files

- Avatars (PNG, JPG, SVG)
- Custom presets (JSON)
- Personal data (CSV, JSON)
- AI training data
- Documents and reports

## Quota

- Default: 500MB per user
- Premium: 5GB per user
- Enterprise: Custom limits

## Privacy & Security

- Files are encrypted at rest
- Access controlled by user authentication
- Automatic cleanup of old/unused files
