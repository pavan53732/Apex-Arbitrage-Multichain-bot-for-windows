# CSV Data Uploads

Upload CSV files for analytics, training data, and trade logs.

## Supported Formats
- Delimiters: comma, semicolon, tab
- Encoding: UTF-8, UTF-16, ASCII
- Max size: 100MB per file

## Use Cases
- Trade history logs
- AI/ML training datasets
- Analytics and metrics data
- Custom data imports

## Import Tips
- Ensure proper headers in first row
- Use consistent date formats (ISO 8601 recommended)
- Validate data before upload
