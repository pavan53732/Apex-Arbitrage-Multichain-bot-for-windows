# Model Weights

Upload AI/LLM/XAI model weights for custom models and plugins.

## Supported Formats

- `.bin` - Binary model weights
- `.onnx` - ONNX format
- `.pt` / `.pth` - PyTorch checkpoints
- `.ckpt` - TensorFlow checkpoints

## Size Limits

- Max file size: 5GB per file
- Recommended: Use compression for large models

## Security

- All uploads are scanned for malware
- Model validation performed on upload
- Version control and rollback supported
