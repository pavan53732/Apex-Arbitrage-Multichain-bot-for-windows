# Dashboard Presets

Backup, restore, and share dashboard configurations.

## Format

- JSON format with full state snapshot
- Includes: theme, layout, widgets, settings
- Version-controlled for compatibility

## Usage

- Auto-backup: Daily snapshots
- Manual backup: Export anytime
- Restore: Select preset and apply
- Share: Export and import across users/teams

## Multi-User Support

- Per-user presets
- Team/organization presets
- Template presets for quick start
